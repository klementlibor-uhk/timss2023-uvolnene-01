Novinky: společný trénink včetně zlomků, kartiček, kreslení a rozbalovací nabídky;
vlastní potvrzení nového pokusu a návratu; tisk odpovědí; sjednocení označení úloh;
odstranění napovídajících nadpisů; nová vysvětlení; úprava výsledků a certifikátu;
informace o soukromí. Žádné odesílání jmen ani výsledků.

Před konečným nasazením na kvalitniskola.cz sladit informaci o soukromí
se skutečným nastavením hostitelského webu.
