# Matematický test č. 1 – verze 6

Rozbalte ZIP a nahrajte celý obsah do kořene repozitáře GitHub Pages. Úvod je index.html.
Test má 11 úloh a maximum 12 bodů. Předchozí pravidla bodování zůstávají zachována.

Nové: nepovinné jméno (jen sessionStorage této karty), přepínání zlomek/číslo a vymazání celé odpovědi,
větší cílová políčka pro šneky s ukazateli a vysvětlení po odevzdání u úloh 1, 2, 8.
Správné řešení úlohy 5 zobrazuje svislý zlomek 5/4. Tisk tvoří jednostránkový certifikát A4.
V tiskovém dialogu doporučujeme vypnout záhlaví/zápatí prohlížeče. Certifikát nevyžaduje tisk pozadí.
Obnovení stránky testu zahájí nový pokus; odpovědi se neukládají ani nikam neposílají.
Jméno lze vymazat na úvodní stránce; konec relace karty je odstraní dle chování prohlížeče.

Pravítko a jeho stránka jsou zachovány ve zdroji rad, ale vynechány z visibleSteps a tlačítko je skryté.
Společné prvky pro budoucí testy: snail-track.js, keypad.js, v4.css, profile.js.


Verze 5: přehlednější úvod, úspornější rozložení rad, značky přímo u bodů, šneci na levém začátku, certifikát a nové názorné vysvětlení sčítání zlomků. Bodování beze změny.


Verze 6: větší úvod, odpovědi v radách pod sebou, větší šneci a cestičky, výchozí prostor mimo odpovědní políčka, přesné značky a grafické vysvětlení úlohy 9.
